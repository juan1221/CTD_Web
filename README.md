# CTD front-end prototype

Responsive static implementation based on the supplied CTD technical brief and Home wireframes.

## Files
- `index.html`: Home page
- `solution-rd360.html`: priority solution prototype
- `styles.css`: centralized design tokens and responsive components
- `app.js`: navigation, header state, reveal effects, analytics hooks and form prototype

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Production notes
- Replace image placeholders only with approved/licensed assets.
- Replace the prototype contact handler with a secure server-side endpoint using validation, sanitization, rate limiting and bot protection.
- Do not expose API keys, recipient addresses or credentials in client code.
- Connect approved CMS, localization, legal routes, analytics IDs and consent controls.
- The Google Fonts import is convenient for the prototype. Self-host approved font files for production if required.
